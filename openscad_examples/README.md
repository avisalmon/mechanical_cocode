# OpenSCAD Examples for AI Co-Coding Research

This directory contains OpenSCAD examples that demonstrate the concepts from your text-based mechanical design research.

## Files:

### 1. `simple_gear.scad`
- **Purpose**: Demonstrates parametric gear generation
- **AI Co-Coding Concept**: Shows how simple parameters can generate complex mechanical parts
- **Features**: 
  - Adjustable teeth count and radius
  - Automatic tooth generation
  - Multiple gear positioning

### 2. `parametric_bracket.scad`
- **Purpose**: Demonstrates AI-assisted parametric design
- **AI Co-Coding Concept**: Shows how design intent translates to parametric code
- **Features**:
  - Fully parametric dimensions
  - Automatic hole placement
  - Reinforcement generation

## How to Use:

1. **Open OpenSCAD** (now installed on your system)
2. **File → Open** and select any `.scad` file
3. **Press F5** to preview the model
4. **Press F6** to render the final model
5. **Modify parameters** at the top of each file to see instant changes

## AI Co-Coding Workflow:

1. **Describe your mechanical part** in natural language
2. **AI generates OpenSCAD code** with appropriate parameters
3. **Iterate and refine** the design through code modifications
4. **Export** as STL for 3D printing or STEP for further CAD work

## Research Connection:

These examples demonstrate the key concepts from your research:
- **Text-based description** → **Mechanical geometry**
- **Parametric design** through code
- **AI-assisted** code generation and optimization
- **Collaboration** between human intent and machine precision
